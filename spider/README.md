# ORB WEAVER — Gundam-style Spider Mech

A high-quality, self-contained THREE.js character: a purple/green Gundam-style
**spider mech** that fights with a **pink energy war-axe** (motion-trail on the swing).

- **`spider/spider.js`** — single source of truth for the model + rig + animation.
- **`tools/build-spider.js`** — inlines THREE + spider.js into the deliverables.
- **`spiderbot.html`** — interactive showcase (drag to orbit, click to swing). Open it in a browser.
- **`tools/spider-inspect.html`** + **`tools/shot-spider.sh`** — 6-angle montage rendered headless for design critique.

Controls: drag = rotate · scroll = zoom · **⚔ axe strike** button = swing.
