# 캐릭터 B — 루시엘 (황금 사자의 왕자) · 컷아웃 리깅

파일: `hero-puppet.html` · key: `puppet` · 기법 배지: 「컷아웃 리깅 · Spine식 퍼펫」

## 컨셉
금발의 화려한 왕자 검사. 흰-금 왕실 예복, 진홍 하프케이프, 레이피어. 펜싱풍 우아함 + 장난기.
전신 정면-3/4 뷰. 분위기: 따뜻한 궁정, 금빛.

## 팔레트
- 머리: base #f4de9c / shade #d9b45e / deep #a9823a / 림 #fff3c9
- 의상: 아이보리 #f7f3e9, 금 트림 #d4af5a, 네이비 포인트 #2b3a5c, 케이프 진홍 #b03042/#7e2231
- 레이피어: 밝은 강철 + 금 가드
- 배경: 웜 다크 #1c1410, 금빛 보케 입자, 궁전 아치 실루엣

## 기법 정의 (이게 이 페이지의 정체성)
- **파트를 초기화 때 딱 한 번** 오프스크린 캔버스에 그린다 (~20개+: 머리, 앞머리, 뒷머리, 얼굴(눈 뜸/반/감음, 입 변형 세트), 몸통, 골반, 상완·하완·손 L/R, 허벅지·정강이·부츠 L/R, 케이프, 레이피어, 칼집 등).
- 매 프레임은 **리지드 트랜스폼만**: 씬그래프(parent, pivot, x, y, rot, scale, z순서)로 조각을 회전/이동. 몸을 매 프레임 다시 그리지 않는다(이펙트 제외) — 절차적 방식과 차별화되는 지점.
- 관절 이음새는 파트에 구운 원형 캡으로 은폐.
- 키프레임 시스템: 노드별 트랙 {t, rot/x/y}, 큐빅 이징, 애니 간 크로스페이드 0.25s.

## 애니메이션 (버튼)
1. **대기**: 호흡, 케이프 흔들림, 가끔 머리 기울이며 윙크.
2. **인사**: 궁정식 보우 — 케이프 플러리시 + 팔 스윕.
3. **찌르기**: 펜싱 런지 — 뒤로 재기 → 폭발적 전진 런지(케이프 휩) → 홀드 → 복귀.
4. **점프**: 웅크림 → 체공(다리 모음) → 착지 스쿼시.
5. **승리**: 레이피어 들어올리고 케이프 펄럭, 반짝 이펙트.

## 인터랙션 (퍼펫의 재미)
- **손/검끝/발을 마우스로 드래그** → 해당 팔다리에 2본 IK 실시간 적용, 놓으면 스프링 복귀. 머리 드래그 → 갸웃.
- 커서 grab/grabbing.

## UI
애니 버튼 5개 / 「뼈대 보기」: 금색 피벗 점 + 계층 라인 + 파트 외곽 희미하게 / **「부품 분해」 버튼: 모든 파트가 격자로 날아가 정렬되고 이름표가 붙는 분해도** (컷아웃 쇼케이스의 백미) / 속도 슬라이더.

## 몽타주 특화
- Row A: 대기 3위상 + 인사 3키.
- Row B: 런지 6키 (준비→재기→발사→극점→홀드→복귀).
- Row C-④: 부품 분해도 (이름표 포함).
