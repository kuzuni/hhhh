# 리코 ver.A — 절차적 스켈레톤 + IK

파일: `chibi-bone.html` · key: `cbone` · 기법 배지: 「절차적 스켈레톤 · IK」

먼저 정독: `spec-common.md`(하드 제약·몽타주·자가검증 루프) → `spec-chibi-common.md`(치비 아트·아바타 시스템).

## 기법 정의
- hero-blade.html(아스렐)과 같은 계열: 본 계층(pelvis→spine→head, 팔다리)을 **매 프레임 커브로 계산**, 드로잉은 본 행렬에서 파생. 치비 비율에 맞춰 본은 짧고 굵게.
- **2본 해석 IK**: 걷기 발 접지(미끄러짐 0), 대검 양손 그립.
- 치비 전용: 모든 본에 **스쿼시&스트레치 스케일 채널** — 착지 시 몸 전체가 납작→쫀득하게 복원.
- 아바타는 "본에 붙는 드로잉 함수 세트"를 통째로 교체하는 구조로 (draw(bone) 콜백 스왑) — 리그·애니 데이터는 공유.

## 팔레트/배경
밝은 하늘+뭉게구름+풀밭 언덕, 채도 높은 명랑 톤. 해질녘 아님 — 낮.

## 애니메이션 (버튼)
1. **대기**: 리듬 바운스, 트윈테일 통통, 귀 쫑긋, 깜빡임, 가끔 두리번.
2. **총총 걷기**: 잰걸음 + IK 접지, 몸 통통 튐, 테일 출렁.
3. **대검 풀스윙**: 뒤로 크게 재기(몸 비틀림 과장) → 풀스윙(검이 화면을 쓸며 별·임팩트 이펙트) → 회전 관성으로 한 바퀴 비틀 → 헤헤 복귀.
4. **폴짝 점프**: 웅크림(납작) → 폴짝(쭉 늘어남) → 착지 스쿼시 + 먼지 퐁.
5. **기쁨**: 제자리 방방 + 하트/별 파티클.
