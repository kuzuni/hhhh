## 하드 제약
- **단일 HTML 파일**, 외부 리소스 0개 (CDN/웹폰트/이미지/fetch 금지 — 모든 그래픽은 코드로 그린다)
- **Canvas 2D만** 사용 (WebGL 금지 — 헤드리스 `--disable-gpu` 스크린샷으로 검증하기 때문)
- 폰트 스택: `"Segoe UI","Malgun Gothic",sans-serif` (시스템 폰트만)
- 반응형 풀뷰포트, 60fps 목표, `dt` 클램프(≤50ms), devicePixelRatio 대응
- **필수**: `window.onerror` + `unhandledrejection` 핸들러 — 에러 메시지를 화면 좌상단에 빨간 글자로 캔버스/DOM에 표시 (헤드리스 샷에서 에러가 보이게)
- UI 텍스트는 한국어. 페이지 `<title>` 지정.
- 좌상단에 작은 링크: `<a href="heroes.html">← 용사 전시관</a>`
- 파일 상단에 섹션 맵 주석 (`// ==== 1. 팔레트 ==== / 2. 리그 / 3. 애니 / 4. 렌더 / 5. UI / 6. 몽타주 ====` 식) — 후속 수정자가 탐색하기 쉽게.

## 아트 디렉션 — 미소년 얼굴이 승부처다

### 비율
- 7등신 내외. 어깨폭 = 머리폭 × 1.6~1.8 (과장 금지). 허리 가늘게, 다리 길게(전신의 52% 이상). 손 크기 = 얼굴 세로 × 0.75 (장갑 추천 — 손가락 디테일 부담↓).

### 얼굴 (클로즈업 450px에서도 버틸 디테일로)
- 두상: 계란형 베지어. 턱끝은 좁고 살짝 뾰족한 V라인, 광대는 완만. 턱선을 귀 밑에서 급하게 꺾지 말 것.
- **눈 (가장 중요)**: 아몬드형, 가로:세로 ≈ 2.2:1. 위 눈꺼풀 라인 굵게(속눈썹 뭉침, 눈꼬리 방향이 캐릭터 성격), 아래 라인은 얇고 연하게 2/3만.
  - 홍채: 세로로 약간 긴 타원, 지름 ≈ 눈 세로의 90%. 3톤 그라데이션(위 어둡고 아래 밝음) + 동공 + 상단 큰 하이라이트 1 + 하단 작은 반사광 1.
  - 쌍꺼풀 라인 얇게. 두 눈 사이 간격 = 눈 가로폭 1개.
- 눈썹: 얇고 긴 곡선, 눈보다 살짝 길게.
- 코: 콧대 생략, 코끝만 짧은 획/점 그림자. 입: 작게, 입꼬리 미세 표정. 아랫입술 밑 옅은 그림자 1획.
- 피부: 베이스 + 뺨/코끝/귀 아주 옅은 혈색 + 턱밑·목 셀셰이딩 1톤.
- 목: 가늘게(얼굴 폭 × 0.45), 쇄골 라인 힌트.

### 머리카락
- 레이어 순서: 뒷머리 실루엣 → 얼굴/몸 → 앞머리.
- 앞머리 8~14가닥: 뿌리→끝 테이퍼되는 닫힌 베지어 도형. 눈썹~눈을 일부 가리게. 눈을 가리는 1~2가닥은 alpha 0.85 반투명으로 눈이 비치게 (고급 연출).
- 3톤: 베이스 / 안쪽·목덜미 그림자 / 정수리 림라이트 밴드(지그재그 톱니 활 모양).
- 움직임에 가닥 끝이 지연되어 따라옴 (오버랩).

### 선·셰이딩
- 외곽선: 순검정 대신 톤 있는 다크(예 #1a1520). 굵기 가변 — 실루엣 굵게, 내부 디테일 얇게. lineJoin/lineCap `round`.
- 셀셰이딩 1~2톤 + 림라이트. 금속은 그라데이션 + 스펙큘러 획.

## 애니메이션 원칙
- 모든 보간에 이징. 선형 보간 금지.
- 오버랩/팔로스루: 머리카락·망토·소매는 몸보다 늦게 따라온다 (스프링 or 지연 체인).
- 공격: 예비동작(0.15~0.25s 뒤로 당김) → 타격(2~3프레임 급가속 + 스미어/잔상) → 임팩트 홀드(2~4프레임) → 회수(느리게).
- 걷기: 발 미끄러짐 금지(접지), 골반 상하 진폭, 어깨 역회전.
- 아이들: 호흡 sin, 눈 깜빡임(2~5초 간격, 가끔 더블), 무게중심 미세 이동.

## 몽타주 모드 `?montage` — 필수 (심사에 사용)
URL에 `?montage`가 있으면 rAF 루프 대신 **로드 즉시 동기적으로** 1680×1500 고정 캔버스에 라벨 그리드를 그린다 (헤드리스 virtual-time-budget 4초 안에 완료돼야 함):
- **Row A** (6칸): 주 모션(스펙 참조)을 고정 위상 t = 0, 1/6, …, 5/6 에서.
- **Row B** (6칸): 액션 시퀀스 핵심 프레임 6개 (예비→타격→홀드→회수 순서 라벨).
- **Row C** (4칸): ① 전신(또는 상반신) 뷰티샷 ② **얼굴 클로즈업 — 머리 세로 ≥ 450px** ③ 리깅 오버레이(뼈/피벗/와이어프레임) ④ 기법 특화 컷(스펙 참조).
- 각 칸 하단 흰색 라벨, 어두운 배경 + 얇은 그리드선.
- 구현: 포즈 계산을 `pose(anim, t)` 류의 **순수함수**로 분리해 실시간/몽타주 공용으로 쓸 것.

## 스크린샷 자가검증 루프 — 필수, 최소 4회 반복
1. `bash tools/shot2.sh <파일>.html?montage tools/<key>_iter<N>.png` (리포 루트에서; 동시 실행 안전)
2. **Read 도구로 PNG를 직접 보고** 결함 목록 작성: 얼굴이 진짜 미소년으로 보이는가? 비율? 실루엣? 관절 어색함? 잘림? 라벨?
3. 수정 → 재촬영. **얼굴이 예쁘지 않으면 될 때까지 반복하라. 이게 1순위다.**
4. 일반 모드(쿼리 없음)도 `bash tools/shot2.sh <파일>.html tools/<key>_live.png 1280,800`으로 1회 촬영 — 빈 화면/에러/UI 확인.
5. 최종 몽타주를 `tools/<key>_final.png` 로 저장하고 마지막으로 한 번 더 눈으로 확인.
