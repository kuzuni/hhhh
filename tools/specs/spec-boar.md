# 몬스터 A — 뚱멧돼지 「투기」 (기본 ↔ 불속성)

파일: `boar-bone.html`(key `bbone`) / `boar-puppet.html`(key `bpup`) — 자기 파일명에 맞는 기법 규칙(spec-monster-common §기법별 요구)을 따를 것.

## 외형 (레퍼런스 충실 재현)
- 몸: **거의 구형에 가까운 통통한 덩어리** — 머리와 몸 경계 없이 한 덩어리, 진한 회갈색(#54463e 베이스, 배쪽 #6b5a50 밝게, 그림자 #3c322c).
- 갈기: **카키/탄색(#b89a5a) 뾰족 모히칸** — 정수리에서 등마루까지 삐죽 스파이크 6~9개, 끝이 살짝 젖혀짐. 그림자 톤(#8a7340) 레이어.
- 얼굴(몸 앞면): 화난 표정 — **노란 눈(#e8c03c) + 검은 동공**, 잔뜩 찌푸린 눈두덩(사선 주름), 미간 주름.
- 주둥이: 크고 둥근 **회분홍(#9a7a72) 코** — 콧구멍 2개 뚜렷, 씩씩 콧김.
- 엄니: 아래턱에서 위로 굽은 **흰 엄니 2개** (입 양옆).
- 귀: 작고 뾰족, 안쪽 분홍. 다리: 아주 짧고 뭉툭한 4개(발굽 진한색). 꼬리: 짧은 곱슬.
- 배경: 풀밭 필드 — 밝은 초록 잔디 + 뒤로 연한 수풀 실루엣, 낮.

## 변주 아바타 「불속성 멧돼지」
- 갈기 → **실시간 일렁이는 불꽃**(뿌리 빨강 #e84c2c → 끝 노랑 #ffd54a, 플리커 애니).
- 몸 → 숯 차콜(#2e2624), **균열 사이로 마그마 글로우**(#ff7a3c 맥동).
- 눈 → 주황 발광(글로우 헤일로), 콧김 → 연기+불티, 발걸음마다 불씨 파티클.
- 엄니는 그대로 희게 (대비 포인트).

## 애니메이션 (버튼)
1. **대기**: 무게감 있는 호흡(몸 전체 들썩), 씩씩 콧김(콧김 퍼프 2박자), 귀 파닥, 가끔 앞발로 땅 긁기.
2. **뒤뚱 걷기**: 짧은 다리 총총 + 몸이 좌우로 크게 뒤뚱, 접지 미끄러짐 없이.
3. **돌진**: 뒤로 갸우뚱 재기(앞발 땅 긁기 2회) → 부앙! 대시(모션 블러+먼지 구름) → 급정지 미끄러짐.
4. **피격**: 움찔 스쿼시 + 별 뿅 + 뒤로 밀림.
5. **죽음**: spec-monster-common 규칙. **조각 = 만화 햄 2~3개(둥근 분홍 단면 + 중앙 흰 뼈 원), 스테이크 슬라이스 2~3개(붉은 살 + 크림색 지방 마블링 단면), 소시지 1~2개.** 불속성이면 조각이 **구운 고기**(갈색 그릴 자국 + 김 모락모락)로 — 디테일 포인트.
6. **부활**: 조각 역재생 흡수 → 뿅 복원.
