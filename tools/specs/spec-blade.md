# 캐릭터 A — 아스렐 (銀月의 검성) · 절차적 스켈레톤 + IK

파일: `hero-blade.html` · key: `blade` · 기법 배지: 「절차적 스켈레톤 · IK」

## 컨셉
은백색 장발(낮은 포니테일)의 냉정한 검성. 청강(靑鋼) 코트, 장검. 달밤(銀月 모티프)의 검무.
전신 3/4 측면 뷰. 분위기: 차갑고 우아함.

## 팔레트
- 머리: base #eef1f6 / shade #b9c3d4 / deep #8b97ad / 림 냉백색
- 코트: #2c3e63, 그림자 #1e2b47, 은 트림 #cfd6e4, 안감 살짝 보이는 남색
- 검: 강철 그라데이션, 트레일 #9fd8ff→#ffffff
- 배경: 밤하늘 #0b0e1a, 창백한 보름달 #e8ecf2(크게, 캐릭터 뒤), 안개층, 떠다니는 입자, 바닥 은은한 반사

## 기법 정의 (이게 이 페이지의 정체성)
- 본 계층: pelvis(root)→spine1→spine2→chest→neck→head, chest→clavicle L/R→upperArm→foreArm→hand, pelvis→thigh L/R→shin→foot→toe.
- **매 프레임 애니 커브에서 본 트랜스폼을 계산**하고, 모든 드로잉은 본 행렬에서 파생. 팔다리는 관절에서 **부드럽게 휘는 테이퍼 곡선**(베지어 캡슐)으로 그린다 — 리지드 조각 회전(컷아웃)과 차별화되는 지점.
- **2본 해석적 IK**: 다리(보행 중 발 접지 타깃 — 미끄러짐 0), 팔(베기 시 양손 그립).

## 애니메이션 (버튼)
1. **대기**: 호흡, 포니테일·코트자락 스프링 스웨이, 검끝 미세 흔들림, 깜빡임.
2. **걷기**: 접지 IK, 골반 상하, 어깨 역회전, 팔 스윙. 발 미끄러짐 절대 금지.
3. **달리기**: 상체 전경, 체공 프레임, 머리카락 크게 날림.
4. **베기**: 3연격 콤보 (횡베기→반전 올려베기→내려찍기). 예비→급가속→임팩트 홀드→회수. 검 궤적 리본 트레일 + 전신 잔상.
5. **발도** (시그니처): 납도 자세 → 섬광 스텝(잔상 3~4장) → 단 한 프레임의 최대 신전 베기(화면 가로지르는 흰-청 아크) → 천천히 납도(찰칵). 시네마틱하게.

## 이펙트
- 검 트레일: 최근 N프레임의 칼끝·칼밑 위치로 페이드 리본 (`globalCompositeOperation:'lighter'`).
- 잔상: 포즈 스냅샷을 실루엣 알파 페이드로.
- 바닥 타원 그림자 + 은은한 반사.

## UI
애니 버튼 5개(한국어) / 「뼈대 보기」 토글: 아트 위에 본 라인+관절 점+IK 타깃+접지 락 표시 / 재생 속도 슬라이더.
