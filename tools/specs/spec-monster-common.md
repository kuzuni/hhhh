# 몬스터 공통 스펙 — 「몬스터 도감」 (2몬스터 × 2기법 × 2아바타)

먼저 `spec-common.md`를 정독하라 — **하드 제약(단일 HTML·Canvas2D만·에러 가시화·한국어 UI·좌상단 heroes.html 링크) / 스크린샷 자가검증 루프(최소 4회) / 완료 보고**는 그대로 적용.
아트 디렉션은 미소년이 아니라 **게임 필드 몬스터** — 카툰풍, 통통, 존재감. 아래가 우선한다.

## 몬스터 아트 디렉션 (공통)
- 카툰 몬스터: 덩어리감 있는 큰 실루엣, 굵고 진한 외곽선, 셀셰이딩 1~2톤 + 밝은 톱라이트.
- 표정·개성 확실하게 (짜증/심술 등). 몸이 크고 다리는 짧고 뭉툭 — 뒤뚱거리는 무게감.
- 배경은 인게임 필드 느낌으로 단순하게 (스펙별 지정). 바닥 그림자 타원 필수.

## 아바타(변주) 시스템 — 필수
같은 리그·같은 애니가 **기본 아바타와 변주 아바타를 그대로 구동**한다. UI에 아바타 토글, 전환 시 뿅 이펙트, 애니는 끊기지 않아야 함. 변주는 색만 바꾸는 게 아니라 **파츠 수준의 차이**(불꽃 갈기, 발광 눈, 뿔 등)를 보여줄 것.

## 죽음 연출 — 이 페이지의 백미 (양쪽 아바타 모두)
**잔인함 0이 절대 규칙**: 피·내장·뼈 파편·신체 부위 조각 금지. 조각에는 눈코입/다리/귀 같은 신체 요소가 전혀 없다. 콘셉트는 "몬스터가 뿅! 하고 **음식 아이템**으로 바뀌는" 게임식 연출 — 오히려 맛있어 보여야 한다.
- 시퀀스: 피격 경직 → **뿅!** (흰 연기 퍼프 + 별 팝, 이 순간 몸이 사라짐) → 그 자리에서 음식 조각 5~8개가 포물선으로 튀어오름 → 바닥에 통통 바운스(스쿼시) → 안착 → 반짝✨ (+김이 모락모락 등 맛있는 연출).
- 조각 종류는 몬스터별 스펙 참조. 각 조각은 **단면이 보이는 음식**으로 정성껏 그릴 것 (만화적 디테일).
- **부활 버튼**: 조각들이 역재생으로 빨려 모이며 뿅! 하고 복원.
- 죽음/부활도 두 아바타 모두에서 작동 (변주 아바타는 조각도 변주 — 스펙 참조).

## 기법별 요구 (파일명이 정한다)
### `*-bone.html` — 절차적 스켈레톤
- 본 계층을 매 프레임 커브로 계산, 드로잉은 본 행렬에서 파생. 몬스터라 본은 적어도 됨(root/몸/머리/턱/귀/다리4/꼬리/갈기·팔 등) — 대신 **스쿼시&스트레치 스케일 채널**을 전 본에.
- 짧은 다리 접지(간단 IK 또는 접지 락)로 뒤뚱 걷기에 미끄러짐 없게.
- 죽음 조각은 **절차 물리**(중력+바운스+회전 감쇠)로 흩어짐.
- 아바타 = 본에 붙는 드로잉 함수 세트 교체 (리그·애니 데이터 공유).
- 「뼈대 보기」 토글: 본·관절·접지 표시.

### `*-puppet.html` — 컷아웃 리깅
- 부품을 초기화 때 1회만 오프스크린에 굽고, 매 프레임은 씬그래프(pivot·rot·z) 리지드 변환만. 키프레임 트랙 + 큐빅 이징 + 크로스페이드.
- **아바타 = 부품 아틀라스 2세트** (뼈·피벗·키프레임 공유).
- 죽음 조각도 **부품**: 죽는 순간 몸 부품을 숨기고 조각 부품들로 스왑, 각 조각이 개별 노드로 물리 낙하.
- 「뼈대 보기」(피벗·계층) + **「부품 분해」** 뷰(이름표, 두 아바타 세트 비교면 가산점).

## 몽타주 배치 (spec-common 규격을 이렇게 덮어씀)
- **Row A** (6칸): 주 모션(대기+걷기) 6위상 — **앞 3칸 기본 아바타, 뒤 3칸 변주 아바타**.
- **Row B** (6칸): **죽음 시퀀스 6키** — 피격 → 뿅(연기) → 조각 튀어오름 → 바운스 → 안착 → 반짝/부활 시작.
- **Row C** (4칸): ① 뷰티샷·기본 ② 뷰티샷·변주 ③ **조각 클로즈업** (음식 단면 디테일이 잘 보이게, 크게) ④ 리깅 오버레이(bone) / 부품 분해(puppet).
- 각 칸 라벨. 두 아바타 모두 몽타주에 반드시 등장.
