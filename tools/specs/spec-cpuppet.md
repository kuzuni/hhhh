# 리코 ver.B — 컷아웃 리깅 (퍼펫)

파일: `chibi-puppet.html` · key: `cpuppet` · 기법 배지: 「컷아웃 리깅 · 퍼펫」

먼저 정독: `spec-common.md`(하드 제약·몽타주·자가검증 루프) → `spec-chibi-common.md`(치비 아트·아바타 시스템).

## 기법 정의
- hero-puppet.html(루시엘)과 같은 계열: 부품을 **초기화 때 1회만** 오프스크린 캔버스에 굽고, 매 프레임은 씬그래프(pivot·rot·z) **리지드 변환만**. 키프레임 트랙 + 큐빅 이징 + 크로스페이드.
- **아바타 = 부품 아틀라스 2세트** (해적 세트 / 마법사 세트). 뼈·피벗·키프레임은 완전 공유, 부품 이미지만 교체 — 컷아웃 리깅의 스킨 교체 개념을 정면으로 보여준다.
- 얼굴 부품(눈 뜸/반/감, 입 웃음/벌림/ω)도 컷아웃 조각으로 — 표정 전환 프레임 애니.
- 관절 이음새는 원형 캡으로 은폐. 치비라 관절이 짧으니 겹침을 넉넉하게.

## 팔레트/배경
아늑한 목조 모험가 길드 안 or 항구 마을 — 웜톤, 랜턴 불빛, 나무 질감 느낌의 단순 도형 배경.

## 애니메이션 (버튼)
1. **대기**: 바운스 + 무기 어깨에 얹고 으쓱, 테일 흔들.
2. **꾸벅 인사**: 크게 허리 숙였다가 반동으로 뒤로 발라당 넘어질 뻔 → 균형 회복 (개그 타이밍).
3. **대검 스윙**: 재기 → 스윙 → 검이 너무 무거워서 같이 반 바퀴 돌아버림 → 어지러움 별.
4. **승리 방방**: 제자리 방방 뛰며 무기 번쩍, 반짝 파티클.
5. **부끄**: 블러시 확 + 손 내젓기 + 고개 도리도리.

## 인터랙션
- 손·무기·테일 **드래그 → 2본 IK**, 놓으면 탱글탱글 스프링 복귀 (치비라 더 과장되게 출렁).
- 머리 드래그 → 크게 갸웃.

## UI
애니 버튼 5개 / **아바타 토글 (해적 | 마법사)** / 「뼈대 보기」(피벗·계층) / **「부품 분해」** — 두 아바타의 부품이 좌우로 나뉘어 정렬되는 분해도(이름표 포함)면 최고 / 속도 슬라이더.
