# 캐릭터 C — 카이렌 (흑염의 마검사) · 메시 디포메이션 (Live2D식)

파일: `hero-live.html` · key: `live` · 기법 배지: 「메시 디포메이션 · Live2D식」

## 컨셉
흑자색 머리, 호박색 눈의 과묵한 마검사. 상반신(버스트업) 초상. 하이칼라 다크 코트+은 클래스프, 어깨 너머 검 자루, 주위에 보라 흑염 위스프. **마우스를 따라 고개·시선이 도는 살아있는 초상화.**
분위기: 요염하고 미스터리. **얼굴 퀄리티가 이 캐릭터의 전부다 — 가장 공들일 것.**

## 기법 정의 (이게 이 페이지의 정체성)
- **레이어별 텍스처를 초기화 때 한 번** 오프스크린에 그린다 (15~20장): 뒷머리 / 몸통·코트 / 목 / 얼굴 베이스 / 귀 / 눈흰자 / **홍채 L·R(시선용 별도 레이어)** / 윗눈꺼풀 L·R(블링크) / 눈썹 L·R / 입(표정별 변형) / 앞머리 3~5그룹 / 옆머리 가닥 / 칼라 / 귀걸이 등.
- 각 레이어를 **격자 삼각 메시**(약 6×8)로 분할. 정점마다 파라미터 가중치를 두고, 파라미터 합산으로 정점 오프셋 → **선형 블렌드 변형** (Live2D식 블렌드셰이프).
- 파라미터: angleX(요 ±30°), angleY(피치 ±20°), angleZ(롤 ±10°), eyeX/eyeY, blink, breath, mouth, hairSway…
- Canvas2D 텍스처 삼각형 렌더: 삼각형마다 clip + setTransform(uv→xy 아핀) + drawImage. **삼각형을 무게중심 기준 ~0.5px 팽창시켜 이음새 실금 방지 — 중요.**
- **레이어별 깊이 계수로 시차(parallax)**: 요 회전 시 앞머리는 +방향, 뒷머리는 −방향으로 더 크게 이동 → 3D 착시.

## 행동
- 마우스 추적: 임계감쇠 스무딩으로 고개+시선이 커서를 따라옴. 마우스 없으면(헤드리스 포함) 느린 8자 드리프트.
- 자동 깜빡임(2~5s, 가끔 더블), 호흡(어깨·가슴 3.2s 루프), 머리카락 스프링 체인 물리(고개 움직임+미풍에 반응), 유휴 미세 스웨이.
- 흑염 위스프 파티클이 캐릭터 주위를 흐름.

## UI
- **표정 버튼**: 기본 / 미소 / 진지 / 놀람 / 윙크 — 입 텍스처 교체 + 눈꺼풀·눈썹 타깃 크로스페이드.
- 「메시 보기」 토글: 삼각 엣지를 시안 알파로 오버레이.
- 파라미터 슬라이더 패널 (angleX/angleY/angleZ/blink…) — 드래그 중엔 추적 대신 슬라이더 우선.

## 몽타주 특화 (마우스 없는 헤드리스 → 파라미터를 직접 지정해 결정론적으로)
- Row A: 고개/시선 6포즈 (yaw −30/−15/0/+15/+30 + 피치 업) — 시차가 보이게.
- Row B: 표정 5개 + 블링크 중간 프레임.
- Row C: ① 버스트 뷰티샷 ② 얼굴 클로즈업(≥450px — 최대 크기로) ③ 와이어프레임 오버레이 ④ 극단 변형(yaw+pitch 최대 + 머리카락 스윙) — 변형 견고성 증명.
