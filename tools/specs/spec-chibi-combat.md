# 리코 전투 업그레이드 — 베기 모션 6종 + 스킬 이펙트 3종

대상: `chibi-bone.html` 과 `chibi-puppet.html` (이미 완성되어 배포된 페이지의 **업그레이드**. 기존 구조·애니·아바타 시스템을 퇴행 없이 유지하면서 추가).
먼저 정독: `spec-common.md` → `spec-chibi-common.md` → 대상 파일의 섹션 맵.

## 추가 1 — 베기 모션 6종 (신규 버튼 6개 또는 「베기」 그룹 UI)
전부 대검 기준, 치비답게 과장(몸 비틀림·오버스윙·반동). 각 모션은 예비→타격(급가속+스미어)→홀드→회수 구조.
1. **가로 베기**: 허리 회전 수평 스윙.
2. **내려 베기**: 머리 위로 번쩍 → 콰앙 내려찍기 (지면 임팩트 + 흙 튐).
3. **올려 베기**: 아래에서 위로 퍼올리며 몸이 살짝 뜸.
4. **대각 베기 (袈裟)**: 어깨→반대 허리 대각선, 발 스텝 인.
5. **회전 베기**: 제자리 한 바퀴 스핀 슬래시 (원심력에 테일·의상 원형으로 펄럭, 끝나고 비틀).
6. **2연격**: 가로 → 즉시 리버스 가로 (좌→우, 우→좌 콤보), 둘째 타에 더 큰 스미어.

## 추가 2 — 스킬 이펙트 3종 (토글 또는 버튼 — 어느 베기와도 조합 가능하게)
1. **베기 아크 (기본 이펙트)**: 검 궤적을 따라 흰-하늘색 초승달 슬래시 아크 + 스피드라인 + 잔상 스미어. 모든 베기에 기본 적용.
2. **화염 부여**: 검신이 불타오르고(칼날 따라 불꽃 리본), 베기 궤적이 **화염 아크**(주황→노랑, 불티 파티클 + 잠깐 남는 잔염). 바닥에 닿는 베기는 불꽃 튐.
3. **검기 발사**: 베기 순간 **초승달 검기 프로젝타일**이 전방으로 날아감 (하늘색 발광 크레센트, 날아가며 얇아지다 사라짐 + 화면 밖 임팩트 반짝). 화염 부여 중이면 검기도 화염색.
- 이펙트는 additive(`lighter`) 활용, 치비 톤에 맞게 화사하게. 아바타(해적/마법사) 어느 쪽에서도 동작.

## 몽타주 갱신 — 필수
기존 몽타주를 이렇게 교체/확장 (여전히 1680×1500 안에):
- **Row A** (6칸): **베기 6종 각각의 임팩트 순간** (모션명 라벨, 기본 아크 이펙트 포함).
- **Row B** (6칸): 스킬 이펙트 쇼케이스 — 화염 부여 3키(점화→화염 베기→잔염) + 검기 발사 3키(발사→비행→소멸).
- **Row C** (4칸): ① 뷰티샷·해적 ② 뷰티샷·마법사 ③ 얼굴 클로즈업 ④ 리깅 오버레이/부품 분해 (기존 유지).
