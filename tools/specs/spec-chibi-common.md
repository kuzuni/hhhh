# 치비 공통 스펙 — 「리코, 홍련의 꼬마 모험가」 (2기법 × 2아바타)

먼저 `spec-common.md`를 정독하라 — **하드 제약 / 몽타주 모드 / 스크린샷 자가검증 루프 / 완료 보고**는 전부 그대로 적용된다.
단, 아트 디렉션은 미소년이 아니라 **치비(SD) 여캐**다. 아래가 우선한다.

## 캐릭터: 리코 (Riko)
발랄한 꼬마 모험가 소녀. 레퍼런스 무드: 빨간(주홍) 머리 + 낮은 사이드 트윈테일, **뾰족 엘프 귀**, 거대한 반짝 눈, 몸보다 큰 무기를 신나게 휘두름.

## 치비 아트 디렉션
- **2.5~2.8등신.** 머리가 전신의 ~40%. 몸통·팔다리는 짧고 통통(stubby), 손발은 뭉툭 (미튼/부츠 느낌).
- **얼굴 (귀여움이 전부다)**:
  - 눈: 얼굴 세로의 **~40%** — 거대한 원형~살짝 세로 타원. 홍채 3톤 그라데이션 + 큰 하이라이트 2개 이상 + 아래쪽 밝은 반사. 윗눈꺼풀 라인 굵게, 속눈썹 2~3개 뾰족.
  - 눈썹 얇고 짧게, 코는 아주 작은 점 or 생략, 입은 작게 — 벌린 미소나 고양이입(ω) 허용.
  - **뺨 블러시 필수** (타원 2개, 은은한 홍조). 얼굴형은 둥글고 볼이 통통, 턱은 아주 살짝만 뾰족.
  - 엘프 귀: 머리 옆으로 수평으로 뾰족하게 돌출, 살짝 위아래로 흔들리면 귀여움.
- 머리카락: 주홍~빨강 베이스 + 진한 그림자 1톤 + 밝은 하이라이트. 앞머리는 뭉툭한 큰 가닥 4~6개. 사이드 테일 2개는 물리(스프링)로 통통 튀게.
- 선: 치비는 외곽선을 **좀 더 굵고 균일하게** — 스티커/토이 느낌. 채도 높고 밝은 팔레트.
- 무기·소품 과장: 대검이 캐릭터 키와 비슷하거나 더 크게.

## 아바타 시스템 (필수 — 이 페이지의 핵심 쇼케이스)
같은 리그·같은 애니메이션이 **두 벌의 의상을 그대로 구동**한다는 걸 증명한다. 몸(얼굴·머리카락·피부·귀)은 공통, 의상·모자·무기만 교체.
- **아바타 A 「해적」**: 파란 반다나(백골 문양 프린트), 빨간 스카프(뒤로 나부낌), 크롭 톱+데님 반바지+벨트, 갈색 부츠, **거대한 회색 커틀러스(식칼형 대검)**.
- **아바타 B 「마법사」**: 챙 큰 보라 마녀모자(끝이 살짝 꺾임), 별 장식 케이프/로브, 스트라이프 스타킹+마법 부츠, **별 지팡이**(끝 보석이 빛남), 주위에 반짝 파티클.
- UI에 아바타 토글 버튼 (해적 / 마법사) — 전환 시 뿅! 이펙트(펑 연기나 반짝)와 함께 즉시 스왑. 애니메이션은 끊기지 않고 이어져야 함(같은 리그 증명).

## 애니메이션 톤
치비는 **바운스가 생명**: 모든 동작에 스쿼시&스트레치 과장, 착지 통통, 대기 중에도 리듬감 있게 들썩. 이펙트(별·하트·반짝)를 아끼지 말 것. 배경은 밝고 명랑하게 (기법별 스펙 참조).
