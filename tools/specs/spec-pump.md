# 몬스터 B — 이빨호박 「펌킨조」 (기본 ↔ 악마)

파일: `pump-bone.html`(key `pbone`) / `pump-puppet.html`(key `ppup`) — 자기 파일명에 맞는 기법 규칙(spec-monster-common §기법별 요구)을 따를 것.

## 외형 (레퍼런스 충실 재현)
- 몸: **커다란 주황 호박 몸통이 곧 얼굴** — 세로 골(로브) 5~7개, 로브마다 음영(#ff9a3c 베이스 / #e07820 골 그림자 / #ffb964 하이라이트).
- 이빨: 몸 폭의 대부분을 차지하는 **거대한 앙다문 이빨 그리드** — 아이보리(#f2ead2) 큰 사각 이빨들이 위아래로 꽉 맞물림(부득부득), 이빨 사이 라인 진하게, 잇몸 라인 어둡게.
- 눈: 이빨 위에 **아주 작은 타원 점눈 2개** (간격 좁게) — 덩치와 대비되는 포인트.
- 팔: 어깨부터 **굵은 초록 선인장 팔**(#5a9a3c, 돌기·가시 오돌토돌, 어두운 그림자 #3c7028), 팔끝 뭉툭.
- 머리 위: **꼬불 덩굴 줄기** + 잎 1~2장, 꼭지 주변에 **주황 진액이 흘러내린 자국**(윤기 하이라이트).
- 다리: 짧은 주황 사각 발 2개.
- 배경: 황무지/모래 필드 — 탄 톤 + 마른 덤불 실루엣.

## 변주 아바타 「악마 호박」
- 몸 → 짙은 흑자색(#3a2440), 골 그림자 더 깊게.
- 눈·입 → **잭오랜턴처럼 뚫려서 내부 화염 글로우**(보라 #b06cff→초록 #7cff8a 일렁임). 이빨 그리드는 뚫린 입 안에서 실루엣으로.
- **뿔 2개**(어두운 굽은 뿔), 덩굴 팔 → 가시 많은 암적색(#7e2438), 주위에 도깨비불 2~3개 궤도.

## 애니메이션 (버튼)
1. **대기**: 이빨 부득부득(가로로 갈리는 미세 진동), 진액 꿀렁, 몸 로브가 숨쉬듯 팽창/수축, 덩굴 줄기 흔들.
2. **뒤뚱 걷기**: 사각 발 총총, 몸이 무겁게 좌우 롤, 팔 흔들.
3. **앙! 물기**: 입을 쫙 벌림(이빨 그리드가 위아래로 갈라짐, 안쪽 어둠) → 앙! 깨물기(임팩트 별) → 부득부득 되씹기.
4. **피격**: 움찔 + 씨앗 몇 개 톡 튀어나옴(귀엽게).
5. **죽음**: spec-monster-common 규칙. **조각 = 호박 웨지 3~4개(겉 주황 껍질 + 속 밝은 과육 #ffd9a0 + 씨 2~3개), 둥근 슬라이스 1~2개(씨가 별모양 배치), 꼭지 줄기 1개.** 악마면 조각 속살이 **은은한 보라 글로우** — 그래도 맛있어 보이게.
6. **부활**: 조각 역재생 흡수 → 뿅 복원.
